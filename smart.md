Here’s a cleaner prompt you can drop into Codex:

I don’t like the current website UI, design direction, or color palette. I want us to completely redesign the visual experience and make it look modern, polished, and beautiful.

Before making changes, go online and research design inspiration from high-quality, modern websites in the same space. Look at their layouts, typography, spacing, color systems, cards, buttons, navigation, forms, and overall visual hierarchy.

Use that research as inspiration, but create an original design that fits this website. Don’t blindly copy another website.

Important constraint

This is a UI/UX redesign only.

Do NOT change, remove, rewrite, or break any existing functional code.

Keep all:

* API calls
* Backend logic
* Authentication
* Database logic
* Payment logic
* Form submission logic
* Validation
* Routes
* Webhooks
* Business logic
* State management
* Existing integrations
* Environment variables

exactly as they currently work.

You are only changing the presentation layer.

What I want

* A completely refreshed visual identity
* Better color palette
* Better typography
* Cleaner spacing and layout
* Modern navigation
* Beautiful buttons and form elements
* Better cards/components
* Better responsive/mobile design
* Strong visual hierarchy
* Consistent border radius, shadows, spacing, and component styling
* Professional SaaS/fintech-quality feel
* No unnecessary animations or gimmicks
* Make it feel intentional and premium, not like a template

First inspect the existing codebase and understand the current component structure and styling system.

Then research relevant design inspiration online.

After that, redesign the UI while preserving the existing functionality 100%.

Do not start by rewriting the application architecture. This is a visual redesign, not a refactor.

Before finishing, verify that all existing functionality still works and that the redesign has not introduced regressions.
